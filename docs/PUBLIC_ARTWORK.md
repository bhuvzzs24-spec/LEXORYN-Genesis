# Public repository artwork policy

This repository is a public-safe snapshot of the completed Phase 1 v2 implementation. The procedural 3D planet, controls, camera journey, generated cloud plate, code, tests and documentation are included. The public scene registry uses the generated cloud/city plate for city views.

The owner explicitly directed that the 18 supplied reference images and their derivatives stay out of GitHub because redistribution rights are uncertain. No supplied reference-image binary or earlier Sites history is included. The complete original Phase 1 state and original Git history are preserved locally before this snapshot; the private Site release retains the separately approved artwork. This means the public repository and private deployment have different asset sets and commit hashes.

The generated plate has exact tool/prompt provenance in GENERATED_ASSETS.md. No blanket license is asserted for all project artwork or code. Cinzel and Manrope redistribution notices are preserved with the font files under public/fonts. Future provided/direction-only assets are marked missing in the public registry until separately cleared and supplied.
