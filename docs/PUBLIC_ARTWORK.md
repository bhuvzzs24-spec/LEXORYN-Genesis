# Public artwork policy

The public GitHub repository includes the original procedural planet, source code, tests,14 newly generated environmental plates, mobile copies, an original 3D-render fallback poster and OFL font files with notices. Exact prompts and native dimensions are in PHASE2_GENERATED_ASSETS.md. No blanket license is asserted for the complete project.

The owner said supplied reference-image redistribution rights are uncertain and directed that supplied artwork stay out of GitHub. All85 supplied original/reference-pack images, their crop derivatives, previews, raw folders and temporary reference-city mattes are excluded from the public push. Public documents may inventory filenames, hashes and design observations without embedding supplied binaries. Supplied detail thumbnails are disabled by data/story-distribution.json in the public edition; their concise text inspections remain functional.

The existing owner-private Site and local preserved checkout retain supplied references and clearly labeled inspector concept studies. Public GitHub and private Sites have separate asset sets and commit hashes. Neither Git history is overwritten. Phase1 was backed up before Phase2.
