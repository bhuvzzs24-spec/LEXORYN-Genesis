# Phase2 visual fidelity assets

Sixteen new original assets: eight clean far environments, four genuinely transparent independent architecture layers and four transparent object atlases. Native dimensions below are measured from actual files. Requested4K output is not asserted when the tool supplies a smaller native size. Mobile far copies keep native pixel dimensions with lower delivery compression quality to avoid portrait enlargement of undersized textures. Atlases are cropped only by runtime UV/CSS coordinates, without altering masters or inventing model geometry.
